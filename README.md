# ModelExit — OpenCode 48-Hour Contest Build Kit

**This archive is an implementation brief, not compiled software.** It is designed so OpenCode can turn the included specifications and curated example dataset into a working Windows-first Streamlit application in up to 48 hours.

## Start here
Read [`START_HERE_RU.md`](START_HERE_RU.md), then paste Prompt A from [`OPENCODE_PROMPTS.md`](OPENCODE_PROMPTS.md) into OpenCode with this folder opened as the workspace. Keep [`AGENTS.md`](AGENTS.md) at the project root: OpenCode officially loads it for project instructions.

## Deliverable
Local open-weight AI evaluation app for a concrete SaaS customer-support task, failure-aware recommendations and downloadable Exit Passport. Target contest: **DEV Hacktoberfest Open-Source AI Challenge, Week 2: Side Hustle**.

## Key constraint
**Do not test on every edit.** [`TEST_POLICY.md`](TEST_POLICY.md) defines exactly 3 planned automated gates and 1 final manual check with hard run limits and no repeated repair loops.
